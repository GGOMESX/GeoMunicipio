about=GeoMunicípio lets you type the name of any of Brazil's 5,570 municipalities (accent-insensitive, filterable by state) or its 7-digit IBGE code and instantly zoom to its official IBGE boundary (SIRGAS 2000). The boundary is highlighted on the map and can optionally be stored in a memory layer. Also available from the QGIS Locator bar (Ctrl+K) with the prefix "mun". Data comes from the public IBGE APIs (servicodados.ibge.gov.br); the list of municipalities is cached locally. No external Python dependencies.
    PT-BR: Digite o nome (com ou sem acento) ou o código IBGE de um município e o GeoMunicípio dá zoom no limite oficial do IBGE, destacando-o no mapa e, se desejar, adicionando-o a uma camada.
